# 디자인내일 소개 홈페이지

기존 `2026 디자인내일 회사소개서`를 바탕으로 제작한 반응형 원페이지 소개 사이트입니다.

## 파일 구성
- `index.html` : 페이지 내용 및 구조
- `style.css` : 반응형 디자인
- `script.js` : 모바일 메뉴 동작
- `assets/` : 소개서에서 추출한 포트폴리오 이미지

## GitHub Pages 배포
1. GitHub에 로그인하고 새 Repository를 만듭니다. (예: `design-naeil`)
2. 이 폴더 안의 파일과 `assets` 폴더를 저장소 최상위에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Build and deployment**에서 `Deploy from a branch`를 선택합니다.
5. Branch는 `main`, Folder는 `/ (root)`로 선택하고 Save를 누릅니다.
6. 잠시 후 `https://깃허브아이디.github.io/design-naeil/` 주소로 공개됩니다.

## 수정할 때
회사 정보와 문구는 `index.html`, 색상과 레이아웃은 `style.css`에서 수정할 수 있습니다.

## 확인 사항
- 전화번호, 주소, 대표자, 설립일은 제공된 소개서의 표기를 사용했습니다.
- 외부 Google Fonts를 사용하므로 인터넷 연결 시 Noto Sans KR 글꼴이 적용됩니다.
- 실제 공개 전 대표자명, 주소, 전화번호 및 포트폴리오 공개 가능 여부를 확인해 주세요.
